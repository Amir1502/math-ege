# Учебное ядро: план реализации

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Поставить запускаемый гостевой тренажёр 13 позиций с точной проверкой и сохранением работы.

**Architecture:** Раздельные React-клиент и FastAPI API в модульном монолите. Версионированный контент хранится в JSON, выданные снимки и попытки в PostgreSQL. IndexedDB сохраняет черновики при недоступной сети.

**Tech Stack:** React, TypeScript, Vite, PWA, KaTeX, IndexedDB, Python 3.13, FastAPI, SQLAlchemy 2, Alembic, PostgreSQL, pytest, Playwright, Docker Compose.

**Spec:** `docs/superpowers/specs/2026-11-05-learning-core-design.md`, `docs/api-contract.md`, `technical-spec.md`.

## Global Constraints

- Нумерация № 1–13 берётся из профиля, статус «Проект» виден.
- Числа передаются строками. Float и произвольная погрешность запрещены.
- Максимальная длина исходного поля 64 символа.
- Не менее 50 тестов математической проверки.
- Не менее 44 × 44 CSS px для управляющих элементов; основной текст не меньше 16 px.
- Демо 65 экземпляров не заменяет 650 проверенных задач и 26 проверенных генераторов.
- Секреты, персональные данные и базы не коммитятся.
- `DESIGN.md` и `docs/api-contract.md` задают общие интерфейсы для параллельных задач.

## Карта файлов

- `backend/app/checker.py`: чистый парсер и точное сравнение.
- `backend/app/content.py`: валидация и чтение профиля, уроков и банка.
- `backend/app/models.py`, `database.py`: хранение гостей, сессий, попыток и идемпотентности.
- `backend/app/schemas.py`: закрытые входные схемы и публичные DTO.
- `backend/app/main.py`, `api.py`, `services.py`: HTTP, права и учебные операции.
- `backend/migrations/`: начальная схема и миграционная среда.
- `backend/content/*.json`: демонстрационный пакет и полный список требований по позициям.
- `frontend/src/lib/`: типы API, HTTP, IndexedDB и сохранение черновиков.
- `frontend/src/components/`: оболочка, математика, поле ответа, состояния запросов.
- `frontend/src/pages/`: план, каталог, урок, настройка практики, задача, журнал и прогресс.
- `frontend/src/styles/`: токены и адаптивная компоновка.
- `frontend/e2e/`: реальные сквозные тесты API и браузера.
- `compose.yaml`, `backend/Dockerfile`, `frontend/Dockerfile`, `infra/nginx.conf`: воспроизводимый локальный запуск.
- `.github/workflows/ci.yml`: тесты, линт, сборка и браузерная проверка.

## Самопроверка плана

Первый этап покрыт четырьмя независимыми проверяемыми блоками. Полный пробник, аккаунты, редактор, методическая рецензия, нагрузка, восстановление и юридический запуск остаются вне этапа и не объявляются готовыми. Общие JSON-поля зафиксированы в одном контракте. Выполнение параллельное с итоговой интеграцией; дополнительных решений от заказчика не требуется.
