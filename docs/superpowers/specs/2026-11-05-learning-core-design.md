# Первый этап: рабочее учебное ядро

## Решение и согласование

Источник требований: `technical-spec.md`, версия 1.0. Заказчик подтвердил первый этап и PWA сообщением «да делай, и больше не спрашивай». Принято предложенное приватное размещение в `Amir1502/math-ege`. Дополнительных вопросов для выполнения этого этапа не требуется.

Это начальный проверяемый срез, а не сдача всего ТЗ. Обязательства по 650 независимо проверенным задачам, 26 генераторам и всем FR/NFR остаются в исходном ТЗ.

## Архитектура

- `frontend/`: React, TypeScript, Vite, PWA, KaTeX, IndexedDB. Один origin для интерфейса и API. Пять пунктов навигации: план, темы, практика, повторение, прогресс.
- `backend/`: FastAPI, SQLAlchemy 2, Alembic, PostgreSQL в Docker Compose. Для запуска без Docker и быстрых тестов допускается SQLite. Проверка использует `fractions.Fraction`, без float.
- `backend/content/`: версионированный JSON-профиль, каталог обязательных навыков, демонстрационные уроки и задачи. Задачи содержат стабильные ID, редакции, семейства, источники и явный статус `demo`.
- Сервер сохраняет неизменяемые снимки выданных задач в сессии. Изменение текущего JSON не меняет старые ответы.
- Гость получает случайный HttpOnly cookie. В базе хранится только хеш токена. Персональные сведения не собираются. История не доступна из другого браузера без этого cookie. Клиент хранит черновик и локальную копию текущей сессии в IndexedDB.

## Пользовательский срез

1. Ученик открывает план и видит проектный профиль 2027, 13 позиций, предупреждение о демонстрационном контенте и гостевом режиме.
2. Он выбирает одну или несколько позиций, серию 5, 10 или 20 задач и начинает без регистрации.
3. Сервер выдаёт только публичные поля задач, без эталона, решения и текста подсказок.
4. Черновик сохраняется локально при каждом изменении. Серверное сохранение сериализовано и проверяет ревизию; при конфликте локальный ввод не перезаписывается.
5. Подсказки открываются по уровням, полное решение отдельно. Помощь до первого ответа отмечается сервером.
6. Допустимый ответ проверяется точно. Неверный формат не создаёт попытку. Повтор с тем же ключом идемпотентности возвращает тот же результат; другое тело с тем же ключом получает 409.
7. Неверный первый ответ не меняется после исправления. Пропуск, помощь и повтор учитываются отдельно.
8. После завершения видны итоги, история и журнал ошибок. JSON-выгрузка не содержит cookie, хешей и служебных секретов.

## Контент и честность

Поставляется отдельный демонстрационный набор: 65 авторских экземпляров, по 5 на позицию; номера 6 и 13 включают по два семейства. Это не проверенный стартовый банк и не доказательство полного покрытия матрицы. Во всех экранах указан статус демобанка. Использование этого набора требует явной настройки `ALLOW_DEMO_CONTENT=true`; при выключении набор не выдаётся.

Профиль перенесён из ТЗ с сохранением статуса «Проект». Независимая актуальная проверка ФИПИ не заявляется. У каждого номера хранится полная обязательная матрица из ТЗ, отдельно от частичного демонстрационного покрытия.

## Границы этапа

Не реализуются вход по email, облачное объединение устройств, пробник с серверным дедлайном, диагностика, административная публикация, окончательный алгоритм освоения и интервальное повторение. Раздел «Повторение» на этом этапе показывает журнал ошибок и запуск нового аналога, не заявляя интервалы 1/3/7/14/30 дней. Статус «Освоено» не выдаётся. Юридически не согласованный публичный запуск не производится.

## Сохранение и безопасность

- Все изменяющие запросы требуют собственный заголовок и проверку Origin. CORS не открывается. Cookie: HttpOnly, SameSite=Strict, Secure в HTTPS-среде.
- Владение сессией проверяется на каждом приватном маршруте. Отсутствующий и чужой объект возвращают одинаковую ошибку 404.
- Публичные DTO формируются белым списком. Включение приватного объекта задачи целиком в JSON запрещено.
- Тексты выводятся React как текст. Только результат KaTeX с `trust: false`, ограниченным расширением и MathML используется как математическая разметка. Произвольный HTML и SVG из JSON не принимаются.
- Длина исходного ответа не более 64 символов. Количество задач, размеры тела и активное время ограничены.
- Очередь повторной отправки хранит исходный ключ идемпотентности. Недоступность API не превращается в неверный математический ответ.
- PWA кэширует только статическую оболочку и ранее открытые уроки. Проверка и новые задачи требуют сети; автономная проверка не заявляется.

## Проверка

Минимум 50 параметризованных тестов числового формата и точного сравнения. Интеграционные тесты FastAPI проверяют приватность DTO, чужие сессии, помощь, первый ответ, исправления, пропуски, сохранение, конфликт ревизии, идемпотентность и выгрузку. Тесты контента проверяют 13 позиций, стабильные ID, привязки навыков, конечный эталон и непустые решения. Браузерный сценарий проверяет гостевой старт, решение, подсказку, перезагрузку и ширины из ТЗ. Производственная сборка TypeScript обязательна. Docker без установленного движка не объявляется проверенным.
