# Автономный Android-тренажёр

Заказчик подтвердил 6 ноября 2026 года автономный APK: встроенные 99 уроков и
845 задач, практика, точная проверка, подсказки, решения и локальный прогресс.
Это следующая очередь раздела 10 исходного ТЗ. Серверная версия и её критерии
не изменяются. Подтверждение относится к этому объёму, не к полной предметной
или эксплуатационной приёмке.

## Архитектура

Отдельная точка входа React, без серверных identity, fetch API и регистрации
service worker. Повторно используются локальные шрифты, KaTeX, безопасный вывод
условий/таблиц/рисунков, токены и элементы интерфейса из существующего клиента.
Одна Android Activity загружает упакованные ресурсы через виртуальный HTTPS
origin внутри WebView. HTTP-сервер, FastAPI и внешний браузер не требуются.
Произвольные URL, сетевые загрузки, file-доступ и JavaScript-мосты запрещены.

Курс берётся из `backend/content/course/`. Build-time манифест фиксирует версию,
SHA-256 трёх JSON и структурные ключи условий из `app.instances.instance_key`.
Никакие reviewer/status не повышаются. Все 845 задач остаются `demo`.
Локальный checker использует BigInt и точные рациональные числа с грамматикой
`app/checker.py`: 64 символа, отдельные training/exam, без Number-допуска,
выражений или скрытого округления.

## Данные и практика

Отдельная IndexedDB `math-ege-offline-v1`, отдельный UUID владельца, версия
схемы и происхождение `device`. Серверные DB, cookie, owner ID, pending UUID,
профили и результаты не переносятся и не очищаются. История старого Custom Tabs
остаётся в браузере. Обновление APK не удаляет локальные данные.

Серия 5/10/20 задач, выбор позиции, навыка, семейства и сложности. Используется
конечный банк. Новые условия исключают встречавшиеся 30 дней; дефицит показан
явно, знакомые задачи не подмешиваются. Явный повтор помечен и не даёт второго
самостоятельного достижения. Снимок занятия содержит исходный профиль,
task/revision/seed, условие и материал проверки. Старый снимок не заменяется
обновлённым курсом.

В одной IndexedDB-транзакции сохраняются помощь, попытка, флаги знакомства,
ответ операции и состояние занятия. Повтор одного UUID/тела возвращает тот же
результат, другое тело конфликтует. Ошибка формата не создаёт попытку. Первая
попытка не переписывается исправлением. Черновик и позиция восстанавливаются
после закрытия процесса; ошибка хранения показана, а не скрыта.

Прогресс показывает фактические первые самостоятельные ответы, помощь,
исправления, пропуски и историю занятий. Он не заменяет серверную политику
освоения, не выдаёт прогноз ЕГЭ и не присваивает неподтверждённое «Освоено».
Локальные события не отправляются в облако.

## Интерфейс и Android

Сохраняется `DESIGN.md`: Technical Blueprint, светлая тема, локальные
Inter/Manrope с кириллицей, Lucide, общие токены, управление минимум 44 px.
Первый запуск сразу предлагает занятие. Уроки доступны полностью без прогрева.
Состояния загрузки, пустого банка, ошибки формата/хранения различаются.

Application ID `ru.mathege.preview` и существующий preview-сертификат
сохраняются. VersionCode 2, versionName `0.2.0-offline-preview`. MinSdk 23,
compile/target SDK 37, Build Tools 36.0.0, JDK 17, Gradle 9.5.1 и AGP 9.3.3
не понижаются. Лишние permissions, backup, cleartext и debug запрещены.
Launcher-only проверки заменяются новым адресным offline-контрактом; строгие
dependency/lint/signature проверки не отключаются. Старый APK и его 48 entries,
20 API 23 META-INF warnings и хеши остаются историческими доказательствами,
а не результатами новой сборки.

## Проверка

Checker parity с Python, включая 845 эталонов, Unicode-пробелы, 64/65 символов,
дроби, минус ноль и `9007199254740993`. Контент: хеши, исходные ID/редакции,
ссылки, рисунки и все 13 позиций. Хранилище: рестарт, idempotency/conflict,
помощь, исправление, пропуск, alias и 30-дневная граница.

Отдельный Chromium gate начинает с пустого хранилища, блокирует все API и
внешние запросы, открывает ранее не прочитанный урок, решает практику, проверяет
прогресс и повторный запуск. Старые PWA assertions не меняются. Новый APK
проверяется unsigned/signed отдельно, с сохранением байтов и прежнего ключа.
Первый запуск в авиарежиме, System WebView/OEM/TalkBack и обновление поверх
заполненного APK требуют устройства либо эмулятора; отсутствие измерения
фиксируется как «не проверено».

## Не входит

Email-вход, MFA, облачная синхронизация, серверное удаление, редакторская
публикация, перенос Python runtime-генераторов, авторитетный пробник и
автоматический импорт серверной истории. Их отсутствие показано честно.
Независимая рецензия, правовой режим, устройство и публичный выпуск не
подменяются автономной упаковкой. Репозиторий остаётся приватным.
