# FR-03: базовые математические уроки — план и проверка

**Цель:** восемь коротких оригинальных русских уроков для восполнения предпосылок.
**Основание:** `technical-spec.md`, разделы 4.2 (FR-03) и 5.2 (FR-05),
`docs/superpowers/specs/2026-11-05-completion-design.md`; дизайн согласован.
**Архитектура:** один модуль возвращает отдельные JSON-совместимые записи уроков;
связи строятся по стабильным идентификаторам из `backend/content/profile.json`.
**Средства:** Python из `backend/.venv`, стандартная библиотека, существующие
`ProfileSource`, `Lesson`, pytest и Ruff.

## Файлы и публичная граница

- `backend/app/generators/foundations.py`: `build_lessons(profile: ProfileSource) -> list[dict]`.
- `backend/tests/test_foundations.py`: проверка возвращаемых записей, содержания и математики.
- `docs/course-foundations.md`: план, состав, фактические результаты и границы поставки.

Уроки имеют `slot: 0`, `slot_id: null`, `kind: "foundation"`, собственные
`foundation-*` навыки, `review_status: "demo"`, `author_id: "ai-project"` и
`reviewed_by: null`. `related_slot_ids` обозначают, где пригодится предпосылка;
они не означают освоения навыков экзаменационной матрицы. `prerequisite_ids`
содержат только рекомендации к другим базовым урокам. Доступ к теме свободный.
`family_ids` и `practice_task_ids` остаются пустыми: письменная самопроверка
не является зарегистрированной задачей курса.

## Состав и объём

Все тексты и числовые примеры написаны для этого модуля, без заимствования
формулировок из стороннего банка. В каждом уроке пять разделов, два полностью
разобранных примера, три коротких письменных задания для самопроверки и памятка.
Всего: 40 разделов, 16 разборов, 24 задания самопроверки, 2627 русских слов
в содержимом `sections[].body`.

| ID урока | Тема | Слов в body | Минут | Точные ответы двух разборов |
| --- | --- | ---: | ---: | --- |
| `base-fractions` | Равные дроби, общий знаменатель, умножение и деление | 323 | 5 | `19/12`; `5/6` |
| `base-negative-numbers` | Числовая прямая, модуль, знаки действий | 327 | 4 | `-1`; `15` |
| `base-percentages` | Выбор базы, последовательные изменения, обратная задача | 339 | 5 | `782`; `800` |
| `base-powers` | Целые показатели, ненулевое основание, скобки | 335 | 5 | `2`; `8` |
| `base-roots` | Арифметический корень, область определения, модуль | 341 | 5 | `14`; `2` |
| `base-algebra-expressions` | Подстановка, распределительный закон, сокращение | 312 | 5 | `-18`; `4` |
| `base-coordinates` | Порядок координат, масштаб осей, изменение координаты | 327 | 4 | `(-4; 3)`; `7` |
| `base-linear-equations` | Равносильные преобразования и проверка исходного равенства | 323 | 5 | `11`; `20` |

Подсчёт включает только русские слова в телах разделов: заголовки, формулы,
числа, латинские переменные, примеры и памятки не увеличивают этот показатель.
Слова с дефисом считаются одним словом. Оценка времени — ориентир для чтения
примерно 120–160 слов в минуту и ещё 1–2 минут разбора примеров; это не замер
на учениках. Короткие вычислительные и координатные разборы оценены в 4 минуты,
остальные — в 5. Самостоятельное решение трёх заданий добавляет время.

### Рекомендуемые предпосылки и экзаменационные связи

Матрица сверена с `backend/content/profile.json`, редакция `2026-11-05.1`.
Навык каждого урока имеет тот же суффикс, что его ID, с префиксом
`foundation-` вместо `base-`. Эти восемь навыков отдельны от экзаменационной матрицы.

| Урок | `prerequisite_ids` | `related_slot_ids` |
| --- | --- | --- |
| `base-fractions` | — | `algebra-transformations`, `probability-basic`, `word-problems` |
| `base-negative-numbers` | — | `vectors-coordinates`, `equations`, `derivative-analysis` |
| `base-percentages` | `base-fractions` | `financial-modeling`, `word-problems` |
| `base-powers` | `base-fractions`, `base-negative-numbers` | `algebra-transformations`, `equations`, `financial-modeling` |
| `base-roots` | `base-powers` | `algebra-transformations`, `vectors-coordinates`, `equations` |
| `base-algebra-expressions` | `base-fractions`, `base-negative-numbers` | `algebra-transformations`, `applied-formulas`, `equations` |
| `base-coordinates` | `base-negative-numbers` | `vectors-coordinates`, `functions-graphs`, `derivative-analysis` |
| `base-linear-equations` | `base-algebra-expressions` | `equations`, `applied-formulas`, `word-problems`, `functions-graphs` |

Названия связанных тем присутствуют в теории вместе с объяснением конкретного
применения: доля равновозможных исходов, производительность, координатная разность,
знак значения производной, концентрация, изменение суммы, подстановка или
линейный шаг модели. Привязка обозначает полезную предпосылку, а не покрытие
всего семейства. В текстах прямо разрешён немедленный переход к выбранной теме.

Сборка требует существования всех указанных стабильных ID и сообщает `ValueError`
с отсутствующими ID при несовместимом профиле. Перестановка или перенумерация
позиций, а также отсутствие несвязанной позиции не меняют уроки. Каждый вызов
возвращает новые вложенные списки и словари; изменения одной копии не портят
дальнейшую сборку или переданный профиль.

   JSON-переход и `data_only`; пропусков проверки схемы нет.
5. Команда Ruff, указанная выше: **All checks passed!**, код выхода 0.

Шестнадцать математических проверок заново вычисляют ответы из опубликованных
условий. Для числовых выражений читается буквальная строка арифметики и разбирается
через ограниченное дерево `ast` со значениями `Fraction`; вычисления с `float`
и выполнение `eval` не используются. Точные корни проверяются через `isqrt`
и обратное возведение в квадрат. Для текстовых примеров извлекаются исходные
числа, ставки, масштабы, коэффициенты и координаты. Подстановка выполняется
в исходное выражение или равенство; проверяется порядок координат.
Эталоны не берутся из `answer`, `steps` или внутренних данных сборщика.

Остальные проверки охватывают восемь ожидаемых уникальных тем, объём и время,
наличие ошибки/самопроверки/формулы, ацикличность рекомендаций, известность связей,
собственные ID навыков, демонстрационный статус, отсутствие рецензента,
пустые ссылки на семейства и практику, повторяемость и независимость копий.

Воспроизводимый подсчёт объёма из `D:\math_ege\backend` (Unicode-escape
в регулярном выражении сохраняет смысл при передаче через Windows PowerShell):

```powershell
@'
import re
from pathlib import Path
from app.generators.foundations import build_lessons
from app.schemas import ProfileSource

profile = ProfileSource.model_validate_json(Path('content/profile.json').read_text(encoding='utf-8'))
pattern = r'[\u0410-\u044f\u0401\u0451]+(?:[-\u2011][\u0410-\u044f\u0401\u0451]+)*'
for lesson in build_lessons(profile):
    body = ' '.join(section['body'] for section in lesson['sections'])
    print(lesson['id'], len(re.findall(pattern, body)))
'@ | .\.venv\Scripts\python.exe -
```

## Границы

Это восстановление отдельных предпосылок, а не полноценное освоение нового
экзаменационного семейства. Поддержана содержательная часть FR-03 и часть FR-05:
объяснение, условия, разборы, письменная самопроверка и памятка. Три задания
каждого урока находятся в тексте; у них нет зарегистрированных ID, ступенчатого
интерфейса подсказок или автоматической оценки. Полную учебную цепочку FR-05
по этим файлам принимать нельзя.

Проверена граница сборщика и действующая схема урока. Подключение к общему
пакету курса, API, рекомендациям и клиенту относится к интеграции координатора;
этот протокол не подтверждает поведение пользовательского интерфейса.
Автоматические проверки не являются независимой предметной рецензией,
проверкой педагогической эффективности или внешней сверкой требований ФИПИ.
Все восемь записей остаются кандидатами `demo` с `reviewed_by: null`.
