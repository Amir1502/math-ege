# ЕГЭ Профиль 2027

Неофициальный PWA-тренажёр первой части ЕГЭ по математике профильного уровня с адаптивным интерфейсом. Язык интерфейса и учебных материалов: русский.

## Состояние проекта

Первый этап по [`technical-spec.md`](technical-spec.md): гостевая практика, точная серверная проверка, подсказки, короткие уроки, сохранение черновиков и честная статистика первых ответов. Это не готовая поставка всех требований ТЗ.

- Экзаменационный профиль хранится в данных. № 1–13, максимум первой части 13 первичных баллов. Статус профиля: **«Проект»**.
- Профиль перенесён из ТЗ от 5 ноября 2026 года. Основные числа и проектный статус технически сверены с ФИПИ: [`docs/source-verification.md`](docs/source-verification.md). Полная независимая методическая сверка ещё требуется.
- Поставляемый демонстрационный пакет: **65 авторских экземпляров**, по 5 на номер. Неполное методическое покрытие явно указано. Демозадачи требуют независимой предметной рецензии.
- Требования полной версии **650 проверенных экземпляров и 26 проверенных генераторов** остаются в ТЗ. Демо не заменяет их.
- Нет прогноза 100-балльной оценки, обещания результата и ложного показателя готовности.
- Публичная регистрация и публичный запуск для учеников не настроены. Гостевой доступ привязан к cookie текущего браузера; анонимная история находится на сервере этой среды, черновики дополнительно на устройстве.

Пробник с серверным дедлайном, диагностика, вход по одноразовой ссылке, объединение устройств, административный редактор, интервалы повторения и полноценный алгоритм освоения относятся к следующим этапам. Журнал ошибок не выдаётся за готовый алгоритм интервального повторения.

Исходники: [Amir1502/math-ege](https://github.com/Amir1502/math-ege), приватный репозиторий. Публичное веб-приложение не развёрнуто.

## Локальный запуск без Docker

Нужны Node.js 24, npm и Python 3.13. Python-зависимости устанавливаются только в `backend/.venv`.

### Windows PowerShell

В первом терминале:

```powershell
cd backend
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements-dev.txt
$env:ALLOW_DEMO_CONTENT = 'true'
$env:COOKIE_SECURE = 'false'
$env:ALLOWED_ORIGINS = 'http://127.0.0.1:5173'
.\.venv\Scripts\python.exe -m alembic upgrade head
.\.venv\Scripts\python.exe -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --no-access-log
```

Если `python` в PATH открывает Microsoft Store, используйте полный путь к установленному Python 3.13 для команды создания окружения. Все последующие команды уже используют `.venv`.

Во втором терминале из корня проекта:

```powershell
cd frontend
npm ci --ignore-scripts
npm run dev -- --host 127.0.0.1 --port 5173
```

### Linux / macOS

Первый терминал:

```sh
cd backend
python3.13 -m venv .venv
.venv/bin/python -m pip install -r requirements-dev.txt
export ALLOW_DEMO_CONTENT=true
export COOKIE_SECURE=false
export ALLOWED_ORIGINS=http://127.0.0.1:5173
.venv/bin/python -m alembic upgrade head
.venv/bin/python -m uvicorn app.main:app --host 127.0.0.1 --port 8000 --no-access-log
```

Второй терминал из корня проекта:

```sh
cd frontend
npm ci --ignore-scripts
npm run dev -- --host 127.0.0.1 --port 5173
```

Открыть **http://127.0.0.1:5173**. API проксируется Vite по `/api`. Документация FastAPI: **http://127.0.0.1:8000/docs**. Не меняйте origin браузера на `localhost` без соответствующей настройки `ALLOWED_ORIGINS`.

При `ALLOW_DEMO_CONTENT=false` проверка непроверенного демонстрационного банка закрыта. Это намеренный безопасный отказ, а не неисправность.

## Docker Compose

```sh
cp .env.example .env
```

Заполнить `POSTGRES_PASSWORD` случайным паролем из 64 шестнадцатеричных символов. Затем:

```sh
docker compose up --build -d
```

Открыть **http://127.0.0.1:8080**. База и API не открывают внешних портов. Исходные образы закреплены digest. Подробнее: [`docs/deployment.md`](docs/deployment.md).

**Не удаляйте том `postgres_data` без резервной копии и явного согласия на потерю истории.** Остановить сервисы без удаления данных можно командой `docker compose stop`.

## Проверки

Windows, из `backend/`:

```powershell
.\.venv\Scripts\python.exe -m pytest -q
.\.venv\Scripts\python.exe -m ruff check .
.\.venv\Scripts\python.exe -m pip check
```

Linux / macOS, из `backend/`:

```sh
.venv/bin/python -m pytest -q
.venv/bin/python -m ruff check .
.venv/bin/python -m pip check
```

Из `frontend/`:

```sh
npm run lint
npm test
npm run build
npx playwright install chromium
npm run test:e2e
```

Сквозные тесты самостоятельно запускают API, выполняют production-сборку и поднимают `vite preview` на портах 8000 и 5173. Проверяется настоящий service worker, а не dev-режим Vite. Перед запуском закройте проверочные вкладки и остановите вручную запущенные серверы на этих портах. Для E2E используется отдельная случайно названная временная SQLite-база; пользовательская локальная база не очищается.

Не пересобирайте `dist` под открытой вкладкой работающего preview: смена хешей может сделать старый ленивый модуль недоступным. Порядок безопасного локального обновления и ограничения PWA описаны в [`docs/deployment.md`](docs/deployment.md#обновление-клиента-и-pwa).

PNG-иконки PWA включены в исходники. После изменения `frontend/public/icon.svg` их можно пересоздать командой `npm run icons` из `frontend/` с установленным Chromium Playwright. Генератор сохраняет непрозрачный фон для системной маски; обычная сборка не требует браузера.

CI проверяет Python, клиент, браузерные сценарии и отдельно Compose с PostgreSQL. Фактические результаты и непроверенные пункты записываются в [`docs/verification.md`](docs/verification.md), а не выводятся из самого наличия тестов.

## Правила ответа

- Допускаются целое число и конечная десятичная дробь, точка или запятая, обычный или математический минус.
- В учебной практике допускается равная дробь `a/b` с положительным знаменателем. В экзаменационном парсере дробь через `/` отклоняется.
- Не допускаются `NaN`, `Infinity`, выражения, степени, знак плюс, единицы, разделители тысяч и внутренние пробелы.
- Пустое поле не равно нулю. Максимум исходного ввода: 64 символа.
- Ошибка формата не создаёт математическую попытку. Неверный первый ответ остаётся неверным даже после исправления.
- Подсказка или решение перед первым ответом отмечает помощь; просмотр теории не повышает статистику самостоятельных ответов.
- Обновление страницы восстанавливает сессию и черновик. Без сети текущий черновик сохраняется, но серверная проверка и новая выдача требуют соединения.

## Структура

```text
backend/
  app/          API, данные, проверка и учебные операции
  content/      Профиль, короткие уроки, демонстрационные задачи
  migrations/   Миграции Alembic
  tests/        Числовые, контентные и интеграционные тесты
frontend/
  src/          Интерфейс, типы API и IndexedDB
  tests/        Проверка сохранения и учебных операций
  e2e/          Браузерные сценарии
infra/          nginx
scripts/        Контейнерная проверка через публичный API
docs/           Контракты, план, ограничения и протоколы
```

Архитектура: [`docs/superpowers/specs/2026-11-05-learning-core-design.md`](docs/superpowers/specs/2026-11-05-learning-core-design.md). API: [`docs/api-contract.md`](docs/api-contract.md). Визуальный контракт: [`DESIGN.md`](DESIGN.md). Полное ТЗ не изменено.

## Права и материалы

В банке используются собственные демонстрационные условия и объяснения, подготовленные с помощью ИИ. Внешние банки, рисунки и решения не копировались. ФИПИ указан как источник экзаменационной структуры, не как партнёр проекта. Правовое основание публикации и независимая предметная проверка должны быть подтверждены до публичной поставки. Лицензии сторонних библиотек перечислены в [`docs/dependencies.md`](docs/dependencies.md).
