# Интерфейс «ЕГЭ Профиль 2027»

**THESIS:** Рабочий лист для спокойной самостоятельной практики. Не рекламный лендинг и не игра с сериями посещений.

**WORLD:** Technical Blueprint в светлой теме. Холодный белый фон, графитовый текст, синий акцент на действиях. Тонкие линии организуют содержание, а не украшают его.

**SILHOUETTE:** Узкая навигация слева, широкая рабочая область, компактная колонка с текущим планом. На телефоне рабочая область занимает всю ширину, пять пунктов навигации находятся снизу.

**FEELING:** Ясность: ученик всегда понимает следующий шаг и видит честные данные вместо обещаний балла.

**AUDIENCE:** Ученики 10–11 классов за компьютером после школы или с телефоном в дороге. Они должны начать решать без регистрации и без длинной вводной лекции.

**FIRST VIEWPORT:** Название раздела, видимый проектный статус профиля, одно главное действие «Начать занятие», выбор длины серии, карта 13 номеров и краткое объяснение гостевого хранения.

**SIGNATURE:** Полоса из 13 пронумерованных ячеек показывает именно структуру первой части; выбор ячейки ведёт к соответствующей теме, а не к декоративной диаграмме готовности.

## Контракт

- React + TypeScript, обычный CSS с общими токенами.
- Кириллица: локально поставляемый Manrope для заголовков и Inter для текста; при отсутствии шрифтов используются системные шрифты. Допустимо ограничиться одним Inter с разными начертаниями ради скорости загрузки.
- Один набор Lucide, толщина 1,75 или 2 во всём проекте.
- Основной текст 16 px или крупнее, управляющие элементы минимум 44 × 44 CSS px.
- Одна мягкая семья скруглений 6/10/14 px, отступы кратны 4 px.
- Цвета, размеры, отступы, скругления и время переходов определяются в `frontend/src/styles/tokens.css`.
- Светлая тема обязательна. Тёмная тема не входит в этот этап.
- Основные ширины: 320, 360, 390, 768, 1024 и 1440 CSS px.
- Нет выдуманных данных, отзывов, рейтингов, «готовности 96,7%», декоративных градиентов и принуждения к непрерывной серии посещений.
- Ошибки формата, сети и математического ответа имеют разные тексты. Любой результат сопровождается текстом, а не только цветом.
- Анимация только для перехода состояния, менее 300 мс; `prefers-reduced-motion` отключает её.

**CATALOG:** Из проверенного результата ui-ux-pro-max взяты Minimalism & Swiss Style, светлая палитра с #2563EB, #F8FAFC и #475569. Предложения рекламного лендинга и латинского Figtree отвергнуты. Из viora catalog взято требование проверять кириллицу; игровая стилистика не подходит назначению тренажёра.
